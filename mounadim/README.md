# مِنظَّم

منصة ويب React + TypeScript + Vite لتنظيم المهام والمواعيد والمصاريف والعادات والأهداف والملاحظات والتركيز.

## التشغيل

```bash
cd mounadim
npm install
npm run dev
npm run build
```

## النشر على GitHub Pages

يمكن استخدام GitHub Actions أو تشغيل `npm run build` ثم نشر مجلد `dist`. تم ضبط `base` على `/mounadim/` بما يتوافق مع رابط GitHub Pages للمستودع.

البيانات تحفظ محليًا في المتصفح ويمكن تصديرها من الإعدادات.
